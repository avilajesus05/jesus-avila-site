# Jesús Avila — Coming soon

Página estática en español. Seis figuras sólidas usan Canvas 2D y Matter.js 0.20.0 para simular gravedad, colisiones, rotación y lanzamientos. La biblioteca se incluye localmente en `dist/vendor/` junto a su licencia MIT. Las figuras responden a arrastre con mouse y tacto; Enter o espacio las mezcla. La simulación usa paso fijo, se detiene al reposar u ocultar la pestaña y respeta movimiento reducido.

Los archivos publicados están en `dist/`. Para previsualizar: `node preview.mjs` y abrir la dirección indicada. El nombre y los contactos se editan en `dist/index.html`; la tipografía y la composición en `dist/style.css`.
